## Стек технологий
| Компонент          | Технологии             |
| ------------------ | ---------------------- |
| **Backend**        | Python (FastAPI)       |
| **Frontend**       | React                  |
| **База данных**    | PostgreQSL             |
| **Инфраструктура** | Docker, Docker Compose |

## Версии продукта (Roadmap)

#### **Версия 0.1 – База: доски и карточки**

- Сервер на Python с одним эндпоинтом `/cards` (POST) для создания карточки.
    
- Клиент на React: форма для ввода названия карточки и кнопка «Создать».
    
- При создании карточка появляется на странице (хранится в памяти клиента или в локальном состоянии).
    
- _Цель:_ убедиться, что клиент общается с сервером, данные передаются.
    

#### **Версия 0.2 – Добавляем доски**

- Модели в БД: `Board` (id, title) и `Card` (id, title, board_id).
    
- API: создание доски (`POST /boards`), получение списка досок (`GET /boards`), получение карточек конкретной доски (`GET /boards/<id>/cards`).
    
- На клиенте: переключение между досками (справа список, слева карточки текущей доски).
    
- Карточки отображаются единым списком (без колонок).
    

#### **Версия 0.3 – Колонки (статусы)**

- Модель `Column` (id, title, board_id, order).
    
- У каждой доски теперь есть колонки (при создании доски можно добавить стандартные: «Inbox», «To Do», «Done» или дать пользователю создать свои).
    
- Карточка привязывается к колонке (`column_id`).
    
- API: CRUD для колонок.
    
- Интерфейс доски с несколькими колонками, карточки распределены по ним.
    

#### **Версия 0.4 – Drag-and-drop (перемещение)**

- На клиенте внедряем dnd-kit.
    
- Реализуем перетаскивание карточек внутри колонки (изменение порядка) и между колонками (смена статуса).
    
- Сервер: эндпоинт для обновления позиции и колонки карточки (`PATCH /cards/<id>` с полями `order`, `column_id`).
    
- Аналогично для колонок (перетаскивание колонок для изменения их порядка).
    

#### **Версия 0.5 – Редактирование и удаление**

- Возможность редактировать название карточки (inline или через модальное окно).
    
- Удаление карточки.
    
- Редактирование названия колонки, удаление колонки (с предварительным переносом карточек или каскадным удалением).
    
- Соответствующие API-методы.
    

#### **Версия 1.0 – Расширенный функционал и контейнеризация**

- Добавляем в карточку описание, дату выполнения, метки (цветные теги).
    
- Модальное окно карточки с этими полями.
    
- Поиск по карточкам (по заголовку и описанию) в пределах доски.
    
- Dockerfile для клиента (сборка статики, Nginx) и сервера (Python).
    
- docker-compose.yml для запуска всех сервисов одной командой (клиент, сервер, volume для SQLite).
    
- Проверка работоспособности.
